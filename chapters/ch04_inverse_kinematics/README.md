# 第4章: 逆運動学（IK）

手先の目標位置から関節角を求める逆運動学を、解析的 IK と数値 IK（ヤコビ転置・擬似逆行列・DLS）の両方で実装し、特異姿勢での挙動を数値で確認します。LLM は不要で、すべてローカルで実行できます。

## ファイル

| ファイル | 内容 |
|---|---|
| `transforms.py` / `fk.py` | 第3章からのコピー（4自由度アームの MJCF と順運動学を再利用） |
| `ik_2link.py` | 2関節アームの解析的 IK、ヤコビアン（解析解・数値微分・MuJoCo の一致確認）、特異姿勢付近の関節速度の比較 |
| `ik_numeric.py` | 4自由度アームの数値 IK。3手法を成功率・反復回数・更新量で比較し、届かない目標での挙動も確認 |
| `ik_mujoco.py` | 差分 IK で手先に円を描かせる。位置制御アクチュエータに指令値を送って追従させる |

## 実行方法

```bash
uv sync
cd chapters/ch04_inverse_kinematics
uv run python ik_2link.py
uv run python ik_numeric.py
uv run python ik_mujoco.py
```

`ik_numeric.py` は300個の目標を3手法で解くため、数十秒かかる場合があります。

## 演習（元記事より）

1. `ik_2link.py` の DLS で λ を 0.001 / 0.01 / 0.1 と変え、特異姿勢付近の安定性と正確さのトレードオフを比べる
2. `ik_numeric.py` の IK を、位置に加えて姿勢も目標に含めるよう拡張する（`mj_jacSite` の `jacr` で回転ヤコビアンを取得）
3. `solve_ik` をランダムな初期値で複数回解き、最も誤差の小さい解を返すよう改良して成功率の変化を見る
4. `ik_mujoco.py` で円の周期を 1 秒に縮める、またはアクチュエータの `kp` を変えて追従誤差の変化を見る
5. （発展）`mink` をインストールし、同じ円の追従を mink で実装する
