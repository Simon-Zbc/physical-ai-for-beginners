# 第3章: 座標変換と運動学

回転行列・同次変換行列・クォータニオンを NumPy で実装し、4自由度アームの順運動学を MuJoCo の計算結果と答え合わせします。LLM は不要で、すべてローカルで実行できます。

## ファイル

| ファイル | 内容 |
|---|---|
| `transforms.py` | 回転行列、同次変換、クォータニオン（`[w, x, y, z]` 順）、slerp の関数群 |
| `demo_transforms.py` | 回転の非可換性、カメラ→基部座標の変換、変換の連鎖、クォータニオン、ジンバルロックを数値で確認 |
| `fk.py` | 4自由度アーム（旋回・肩・肘・手首ロール）の順運動学。MuJoCo の `mj_kinematics` と1000姿勢で照合 |

## 実行方法

```bash
uv sync
cd chapters/ch03_kinematics
uv run python demo_transforms.py
uv run python fk.py
```

`fk.py` では、自作の順運動学と MuJoCo の誤差が浮動小数点の丸め誤差レベル（$10^{-16}$ 程度）であること、また MuJoCo のクォータニオンを `xyzw` と取り違えると別の回転になることを確認できます。

## 演習（元記事より）

1. `shoulder` と `elbow` を変えながら手先位置をプロットし、作業領域（Workspace）を可視化する
2. `forward_kinematics` を N 個の関節角をまとめて受け取れるようベクトル化する
3. カメラの取り付け位置を1cm、向きを1°ずらしたとき、物体位置がどれだけずれるかを確認する（ハンドアイ・キャリブレーションの重要性）
4. 回転行列と6D表現（最初の2列）の相互変換を実装する（グラム・シュミットの直交化）
