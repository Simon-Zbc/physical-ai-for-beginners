# 第0章: フィジカルAIとは何か

フィジカルAIの基本ループ **Sense → Think → Act** を、MuJoCo 上の2関節平面アームで実装します。
`think()` がヤコビ転置法によるルールベース制御になっている以外は、以降の章で扱う学習ベースの方策（RL / 模倣学習 / VLA）と同じ構造です。

## ファイル

| ファイル | 内容 |
|---|---|
| `sense_think_act.py` | ヘッドレス版。制御ループを1500ステップ実行し、収束の様子と最終誤差をコンソールに出力する |
| `viewer_demo.py` | ビューア版。MuJoCo のビューアでアームが目標へ動く様子を確認する（ローカルPC専用） |

## 実行方法

リポジトリルートで依存関係をインストールしたあと、このディレクトリから実行します。

```bash
uv sync

cd chapters/ch00_intro
uv run python sense_think_act.py

# ビューアで見る場合（ローカルPCのみ。macOSは python の代わりに mjpython）
uv run python viewer_demo.py
```

## 期待される出力

`sense_think_act.py` を実行すると、手先が目標位置 (0.2, 0.35) へ約0.5秒で収束し、最終誤差はほぼ0mmになります。

```text
t=0.00s  手先=[0.474 0.179]  目標までの距離=0.3230 m
t=0.20s  手先=[0.178 0.368]  目標までの距離=0.0289 m
t=0.40s  手先=[0.199 0.353]  目標までの距離=0.0032 m
...
最終誤差: 0.0 mm
```

## 演習（元記事より）

1. `target` の `pos` を変えて、アームが届く範囲と届かない範囲を確かめる（アームの長さは 0.3 + 0.25 = 0.55 m）
2. `think()` の `kp` / `kd` を変えて、収束の速さや振動の変化を観察する
3. ループの途中（例: `step == 750`）でターゲット位置を変え、追従するか確認する（`model.site_pos[target_id] = [...]` の後に `mujoco.mj_forward(model, data)` を呼ぶ）
